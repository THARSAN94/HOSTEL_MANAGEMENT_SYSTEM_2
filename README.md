# 🏨 Smart AI Hostel Management System
🤖 **Smart AI Hostel Management System** is an AI-powered web application designed to make hostel management **simple, smart, and efficient**. 🏠 It helps manage 👨‍🎓 students, 🛏️ rooms, 📋 attendance, 📝 complaints, 🛫 leave requests, 💰 fees, and 🚪 visitors in one platform. The system also uses 🤖 AI and 📊 analytics to provide smart insights and support better hostel management. 🚀
### 🛠️ Tech Stack
💻 React.js | ⚙️ Node.js | 🍃 MongoDB | 🧠 Python | 🤖 AI/ML

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Set the `GEMINI_API_KEY` in [.env.local](.env.local) to your Gemini API key 
3. Run the app:
   `npm run dev`
